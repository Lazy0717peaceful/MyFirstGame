# MyFirstGame

OpenGLで制作した、シンプルな2Dゲームです。

三角形の自機をWASDキーで操作し、画面上に配置されたターゲットに触れるとスコアが加算され、ターゲットがランダムな位置へ移動します。  
スコアが10点に到達するとゲームクリアです。

## 操作方法

| キー | 操作 |
| --- | --- |
| W | 上へ移動 |
| A | 左へ移動 |
| S | 下へ移動 |
| D | 右へ移動 |
| Esc | 終了 |

## ビルド・実行

現在のMakefileはmacOS向けです。

### 必要な環境

- C++17に対応したClang
- GLFW
- pkg-config

Homebrewを使用する場合は、以下で必要なパッケージをインストールできます。

```bash
brew install glfw pkg-config
```

### ビルド

リポジトリのルートディレクトリで、

```bash
make
```

を実行します。

実行ファイルは `bin/MyFirstGame` に生成されます。

### 実行

リポジトリのルートディレクトリから、

```bash
./bin/MyFirstGame
```

を実行してください。
